# BS·KITAP — кітапхана порталы / Библиотечный портал

Қазақша және орысша. **20 кітап**, ашық/қараңғы режим, жасыл дизайн, PNG иконкалар.

## Мүмкіндіктер

- Сайтқа кіру үшін **әр адам телефон нөмірі мен құпиясөз арқылы тіркеледі**.
- Бір админ өз телефоны мен құпиясөзі арқылы толық басқару панеліне кіреді.
- Тіркелген оқырмандар кітаптарды, қолжетімді дана санын, кітапты кім алғанын және қайтару мерзімін көреді. **Телефон нөмірлері басқа оқырмандарға көрсетілмейді.**
- Оқырман кітапты «Қайтарылды» деп белгілей алмайды. Мұны тек админ жасайды.
- Оқырман «Мен оқығандар» тізіміне кітап қосады, өзіне берілген кітаптарды көреді, жаңа кітап алуға ұсыныс қалдырады.
- Админ кітаптарды қосады/өңдейді/өшіреді, кітапты тегін береді және қайтаруды белгілейді, тіркелген оқырмандар мен ұсыныстарды көреді, CSV және JSON сақтық көшірмесін жүктейді.
- Ешқандай төлем, сауда немесе түбіртек жоқ.

## Windows PowerShell-де іске қосу

1. [Node.js](https://nodejs.org/) 20 немесе жаңасын орнатыңыз.
2. ZIP архивін шығарып, `bs-kitap` папкасына кіріңіз.
3. Папкада PowerShell ашып, төмендегі командаларды **әр жолын жеке** орындаңыз:

```powershell
$env:ADMIN_PHONE="+77760305294"
$env:ADMIN_PASSWORD="ADMIN_PASSWORD"
npm start
```

`+77001234567` орнына **өзіңіздің телефон нөміріңізді**, пароль орнына кемінде **12 таңбалы күрделі құпиясөзіңізді** жазыңыз. Дайын ортақ пароль берілмеген.

4. Браузерде `http://localhost:3000` ашыңыз. Админ ретінде өз нөміріңіз бен пароліңізді енгізіңіз.
5. Басқа адамдар өз телефонымен тіркеліп, содан кейін кіреді.

**Ескерту:** `npm install` қажет емес — сыртқы Node.js пакеттері қолданылмайды.

## Интернетке жариялау

Жергілікті компьютердегі `localhost` басқа адамдарға интернет арқылы ашылмайды. Node.js серверін, HTTPS және **тұрақты диск/дерекқор** беретін хостингке орналастыру керек. `ADMIN_PHONE`, `ADMIN_PASSWORD` серверде құпия environment variables ретінде орнатылады. `PORT` қолданылады. Тегін субдомен хостингтің ағымдағы шарттарына байланысты, автоматты түрде тіркелмейді.

`data/library.json` ішінде телефондар мен оқырмандар деректері сақталады. Бұл файлды **public папкасына көшірмеңіз**, GitHub-қа жарияламаңыз. Қолданба парольдерді scrypt арқылы хэштейді, бірақ ауқымды көпшілік сервис үшін қосымша қауіпсіздік (persistent database, abuse prevention, rate limiting, monitoring, backups, privacy notice) қажет. Сервер қайта қосылса, барлық сессиялар аяқталады.

## Кітап мұқабалары

Нақты баспа мұқабалары берілмеген: 20 кітаптың жеке түсті дизайнерлік мұқабасы бар. Админ кітапты өңдеп, нақты мұқабаға HTTPS URL қоя алады.

## Деректерді сақтау

`data/library.json` — кітаптар, тіркелген оқырмандар, берілімдер, оқылған кітаптар және ұсыныстар. Деректер серверде сақталады. JSON сақтық көшірмесін админ панелінен жүктеуге болады. JSON ішінде құпия парольдің **хэші** мен жеке телефондар бар: файлды құпия сақтаңыз.

## 4.0 дизайн жаңартуы

- Жоғарғы навигация орнына сол жақта орналасқан бөлімдер мәзірі қосылды.
- `❮` батырмасы мәзірді жинайды, `❯` қайта ашады; таңдау браузерде сақталады.
- Телефонда `☰` батырмасы арқылы бүйірлік мәзір ашылады.
- «Мен оқығандар» және админнің басқару беттерінде қайталанған кітап каталогы алынып тасталды. Кітаптар тек «Кітаптар» бөлімінде және басты бетте көрсетіледі.
- Ашық режим: жұмсақ ақ-жасыл. Қараңғы режим: қою жасыл емес, ашықтау бейтарап графит.
- Жалпы өлшемдер, карточкалар және шрифттер ықшамдалды; барлық бастапқы API және рөлдік шектеулер сақталды.
